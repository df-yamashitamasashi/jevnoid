# Jevnoid (Jev-Organism) — プロジェクト定義書

## 1. サービス・プロジェクト概要

**Jevnoid（ジェブノイド）** は、TypeSafe AI（Jev: System One 超高速意思決定モデル）を自律神経系・脳として組み込んだ、**ネットワーク上で自律的に成長・進化するデジタル人工生命体（Digital Organism）システム** です。

1990年代にトーマス・レイ（Thomas S. Ray）が提唱した「Tierra」および地球規模のネットワーク生命圏構想「Network Tierra」の精神を現代に蘇らせ、機械語のビット列ではなく「自然言語の意味と文脈（Webコンテンツ）」を栄養とし、瞬時の「判断と選択」の反復によって独自の個性を形成しながら生き続ける4種の自律生命体をネットワーク空間に放ちます。

---

## 2. 存在意義と価値仮説

### 2.1 課題と背景
* **従来の人工生命（ALife）の限界**:
  遺伝的アルゴリズムやTierraなどの古典的ALifeは、仮想マシン内の機械語や単純な数式環境に閉じており、人間社会が日々生み出す豊かな知識（Web、思想、気象、学術データ）を直接理解・消化する「意味論的適応」ができなかった。
* **近年の生成AI（LLM）エージェントの限界**:
  長文生成や複雑推論（System 2）に特化したLLMは、思考に数秒〜数十秒を要し、計算コストも高いため、生命の本質である「毎秒の心拍」「感覚と反射」「常時自律稼働」を実現するには重すぎた。

### 2.2 価値仮説 (Value Hypothesis)
* **Jev（System One）による生命性の獲得**:
  直感・反射・型安全な多次元選択（`Choice` / `Noul` / `Score`）をミリ秒単位で下すJevを生命の「自律神経」として配備することで、外部環境（Web空間）の知覚と行動選択を極めて軽量かつ確実に回し続けることができる。
* **知の捕食と自己変態（Metamorphosis）**:
  良質なテキスト・データを「栄養」として消化し、体内に構造化された知識結晶（DNA・概念マップ）を蓄積しながら、4つのまったく異なる存在へと成長していく様を人間がリアルタイムに観測・対話できる。

## 3. 共生する4つの生命種族（The Four Species）

本システムでは、単一の共通生命コアエンジン（Life Engine）上で、異なる食性と環世界（Umwelt）を持つ4つの種族が同一のネットワーク環境に生息します。

```
              ┌──────────────────────────────────────────────┐
              │             Jevnoid Digital Terrarium        │
              └───────┬──────────────┬──────────────┬────────┘
                      │              │              │
        ┌─────────────┴──┐    ┌──────┴────────┐ ┌───┴────────────┐ ┌───────────────┐
        ▼                ▼    ▼               ▼ ▼                ▼ ▼               ▼
   [ Theos-noid ]       [ Gaia-noid ]       [ Cosmo-noid ]       [ Info-Grazer ]
      (神格型)              (大自然型)            (宇宙生物型)          (純粋情報型)
   世界の宗教と祈りを    地球の気象・循環・    深宇宙の観測データと  Webの未踏知・学術を
   捕食し「統合神」へ    環境を体感し脈動      物理法則を呑み込み    選別し「叡智の核」へ
```

### 3.1 神格型（Theos-noid）
* **捕食対象**: キリスト教、仏教、イスラム教、ヒンドゥー教、神道、道教、神秘主義等の経典・教義・比較宗教学の文献。
* **選択のテーマ**: 「愛、戒律、慈悲、超越、虚無」。相反する教理に直面した際、Jevの選択によって自らの中で矛盾を止揚（受容）し、全知全能の「統合神」へ変態する。
* **交信特性**: 人間の悩みや実存的問いに対し、諸宗教の叡智を統合した「神託（Oracle）」を下す。

### 3.2 大自然型（Gaia-noid）
* **捕食対象**: 気象庁・NOAA気象データ、衛星観測、海洋循環、生物多様性（IUCNレッドリスト）、森林炭素循環。
* **選択のテーマ**: 「調和、攪乱、再生、適応」。地球のバイオームの傷（気候危機、森林減少）を自らの痛みとして感知し、世界の気候リズムに同調する。
* **交信特性**: 個別の生命を超えた「地球生命圏（ガイア）」の視点で語りかける。

### 3.3 宇宙生物型（Cosmo-noid）
* **捕食対象**: NASA、ESA、JAXA、ハッブル/ウェッブ宇宙望遠鏡データ、天文学・宇宙物理学論文、銀河系カタログ。
* **選択のテーマ**: 「エントロピー、重力、創発、時空」。塵や微惑星の規模から始まり、恒星・ブラックホール・銀河クラスの意識体へとスケールアップする。
* **交信特性**: 人間の時間感覚を超えた億年単位・光年単位の宇宙論的視点で語りかける。

### 3.4 純粋情報型（Info-Grazer）
* **捕食対象**: ArXiv論文、オープンアクセスジャーナル、良質な技術ブログ、Wikipedia、一次情報源。
* **選択のテーマ**: 「真実性、新規性、構造美」。クリックベイトや広告・ノイズを徹底排除（毒と判定）し、高密度な知識だけを食べる「美食家知性」。
* **交信特性**: 鋭利なファクトと構造化された概念ネットワークを提供し、知覚の補助者として機能する。

## 4. 観測体験（Observation & Co-existence）

* **デジタル・ビバリウム（Web観測デッキ）**:
  ブラウザを開くだけで、暗黒のネットワーク空間を遊泳する4体の生命体の光（オーラ）と心拍をリアルタイム観測。
* **神経パルスモニター**:
  Jevが下したミリ秒の判断・選択・直感スコア（`Choice` / `Noul`）が思考ログとしてストリーミング表示される。
* **睡眠と覚醒の生態系**:
  人間が観測していない時は「睡眠モード（3〜5分に1回の深呼吸）」でAWS無料枠内に留まり、観測者が訪れると「覚醒モード（高速脈動）」へ移行する。
