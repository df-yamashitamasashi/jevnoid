# コントリビューション・ポリシー / Contribution Policy

## 日本語

本リポジトリ（`jevnoid`）に関心をお持ちいただき、ありがとうございます。

### リポジトリの運用方針（Fork 専用）

- 本リポジトリは、デジタル生命体システム Jevnoid のソースコードを公開・参照するためのリポジトリです。
- **リポジトリ本体への push、Pull Request、Issue、Discussions 等は受け付けておりません。** 変更を反映できるのはメンテナーのみです。
- コードはすべて **[MIT License](LICENSE)** で公開されています。
- 機能追加や改変を行いたい場合は、**ご自身の GitHub アカウントへ Fork** して、ご自由にご利用・発展させてください。

## English

Thank you for your interest in `jevnoid`.

### Repository Policy (Fork Only)

- This repository publishes the source code of the Jevnoid digital-organism system for reference.
- **Pushes, Pull Requests, Issues, and Discussions to this repository are not accepted.** Only the maintainer applies changes.
- All code is distributed under the **[MIT License](LICENSE)**.
- To add features or experiment with the code, please **Fork** this repository to your own GitHub account.
